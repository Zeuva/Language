Política de Privacidade - Zeuvastec Language

Última atualização: 06/08/2025

1. Dados

Armazenamos localmente: nome, progresso, pontos, simulados, certificados. Não enviamos para servidores.

2. Microfone

Usamos microfone apenas para reconhecimento de voz. Áudio processado localmente via Web Speech API, não gravado.

3. Permissões

RECORD_AUDIO para conversação, armazenamento local para progresso.
